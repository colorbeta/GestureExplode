<h1 align="center">Gesture Explode</h1>

<p align="center">
  一款面向 Android 14+ 打造的纯本地手势启动与全局搜索工具。<br />
  全屏随手一画，秒搜应用、联系人与系统设置。<strong>无联网权限，纯离线运行。</strong>
</p>

## 核心特性

- **全屏手写 · 随手即搜**
  - 取消传统边缘分区死区，全屏任意位置落笔即可书写英文字母、数字与中文拼音首字母，并自动支持驼峰词切分与高频应用常用简称。
  - **单笔智能加速**：一笔成形的弯曲/闭合字符自动缩短识别等待时间；多笔画字母（如 `t` / `f` / `x`）仍留足从容的落笔间隔。
  - **候选一键纠错**：识别上屏后底部浮现「候选」气泡，遇到易混淆字母无需删掉重写，轻点一下即可替换末位。
- **符合直觉的浏览手势**
  - 结果超出一屏时，在屏幕任意位置**垂直向上直滑**即可零延迟切入跟手滚动与惯性滑行；停稳后 **1.2 秒** 内上下往返自由翻页，也可直接拖动右侧快速滑块直达任意位置。
  - 单笔水平向左平划即可快速退格（基于物理 `dp` 距离与直线度防误触）。
- **增强型通讯录检索**
  - 直接展示通讯录真实头像（无头像时自动生成首字圆形徽章）。
  - 同一联系人包含多个号码时自动拆分为多条，并在姓名后括号标注号码类型（如 `家庭` / `公司` / `手机`）。
  - 结果右侧内置快捷操作：**拨号带防误触确认弹窗**，**短信一键直达发送界面**。
- **分品牌系统设置 & 图标包过滤**
  - 自动适配三星 One UI、小米 HyperOS/MIUI、OPPO/一加/真我 ColorOS、vivo/iQOO OriginOS、华为/荣耀及原生 Android 的高频系统设置入口，动态校验本机可跳转页面（如一键直达电池主页面，与省电模式清晰区分）。
  - 自动识别已安装的第三方图标包并独立归类（搜索范围中默认关闭），避免污染应用搜索结果。
- **Material Design 3 界面与可调触感**
  - 全面遵循 Android 14+ Edge-to-Edge 沉浸式与预测性返回规范；浅色模式支持 Material You 壁纸动态取色，深色模式采用高对比度暗夜专属配色，确保笔迹与高亮清晰锐利。
  - 全链路线性马达触觉反馈，支持在设置页中精细调节 **20%–100%** 震动强度。

## 手势速查

| 手势 / 操作 | 作用 |
| :--- | :--- |
| 屏幕任意位置书写 | 识别字母、数字、拼音首字母，多笔画自动合并 |
| 单笔水平向左划 | 退格删除最后一个字符 |
| 垂直向上直滑（列表超出一屏时） | 瞬时切换为列表滚动，并在停稳后 1.2 秒内支持上下往返自由浏览 |
| 拖动右侧药丸滑块 | 快速定位到长列表任意位置 |
| 点击底部「候选」气泡 | 一键替换刚输入的末位字符 |
| 点击联系人右侧电话 / 短信图标 | 弹窗确认拨号 / 直接跳转短信发送框 |

## 环境与权限说明

- **最低系统要求**：Android 14（API 34），原生 64 位架构（`arm64-v8a`）
- **隐私与权限**：本应用**不申请任何网络权限**（`INTERNET`），所有检索与识别完全在本地完成。
  - `QUERY_ALL_PACKAGES`：用于读取本机已安装应用列表以提供本地搜索。
  - `READ_CONTACTS`：用于本地检索联系人姓名、号码与头像（不授权也可正常搜索应用与设置）。
  - `VIBRATE`：用于提供可调强度的触觉反馈。

## 常见问题

### 1. 关于 `f` / `t`、`d` / `o` 等易混淆字母的识别
应用内置 Google ML Kit Digital Ink 离线手写引擎（基于拉丁字符书写习惯训练）。除尽量书写规范或使用大写外，新版在底部搜索栏上方加入了 **「候选」一键替换条**——当系统将 `f` 误识为 `t`（或类似相近字符）时，直接轻点一下候选气泡即可瞬间纠正，无需删掉重写。

### 2. 关于系统设置的覆盖范围
Android 并未提供枚举所有厂商设置子菜单的公开 API。应用已针对主流国产与国际品牌（三星 One UI、小米、OPPO/一加/真我、vivo、华为/荣耀及原生 Android）分别维护了常用设置字典，并在本地通过 `PackageManager` 动态过滤仅展示当前系统实际可跳转的页面，但不同系统版本仍可能存在少量差异。
